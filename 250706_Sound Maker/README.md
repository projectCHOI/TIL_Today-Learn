# Sound Maker 
- Mouse Click 8-bit Composer

**마우스 클릭 기반 8비트 작곡기 (Python / Tkinter / NumPy / Pygame)**

이 프로젝트는 **마우스로 음계를 선택하여 8비트 스타일의 음악을 작곡하고, WAV 파일로 생성·재생·저장**할 수 있는 간단한 작곡 도구입니다.
게임 개발 중 **BGM, 엔딩 음악, 효과음 제작**을 목적으로 설계되었습니다.

## 📌 주요 특징

* 🎹 **마우스 클릭으로 작곡**

  * 도~시 음계 + 옥타브(− / +) 지원
  * 쉼표(무음) 삽입 가능
* 🖼️ **오선지 시각화**

  * 선택한 음이 실시간으로 오선지(Canvas)에 표시
* 🎮 **8비트 사운드**

  * 정사각파(square wave) 기반
  * ADSR Envelope 적용
* 🎧 **WAV 파일 생성 & 재생**

  * 생성 즉시 게임에서 사용 가능
* 💾 **프로젝트 저장 / 불러오기**

  * JSON 기반 작곡 데이터 관리
* ⚙️ **BPM / 음 길이 / 반복 횟수 설정**

## 🛠️ 사용 기술

* **Python 3.x**
* **Tkinter** – GUI
* **NumPy** – 파형 생성
* **SciPy** – WAV 파일 저장
* **Pygame** – 사운드 재생
