# 🎵 Sound Maker: 8-Bit Music Composer

**Python 기반 마우스 클릭형 레트로 사운드 작곡기**

이 프로젝트는 **Tkinter GUI**와 **NumPy 수치 해석**을 결합하여, 음악적 지식이 부족해도 마우스 클릭만으로 게임용 8비트 BGM과 효과음을 제작할 수 있도록 설계되었습니다. 특히 **ADSR 엔벨로프**를 적용하여 단순한 비프음을 넘어선 부드러운 악기 소리를 구현합니다.

---

## 📌 주요 특징

* **🎹 직관적인 3옥타브 작곡**
* 낮은 음(-) / 일반 음 / 높은 음(+) 총 21개 음계 지원
* `쉼표` 기능을 통한 리듬감 조절

* **🖼️ 정교한 실시간 오선지(Staff) 시각화**
* 입력한 음계의 높낮이를 오선지 위에 실시간 렌더링
* 높은음과 낮은음의 위치를 음악 이론에 맞춰 정교하게 배치

* **🎧 고품질 8-Bit 합성 엔진**
* **Square Wave (정사각파)** 기반의 클래식 게임 감성
* **ADSR Envelope** 적용: Attack, Decay, Sustain, Release를 통한 노이즈 제거 및 음색 최적화

* **⚙️ 유연한 설정 및 익스포트**
* 음 길이 선택 (`2분 / 4분 / 8분`) 및 반복(Loop) 횟수 지정
* 생성 즉시 WAV 파일 저장 및 Pygame Mixer를 통한 실시간 재생

* **💾 프로젝트 데이터 관리**
* JSON 포맷을 활용한 작곡 데이터 저장 및 불러오기 기능

## 🛠️ 사용 기술 (Tech Stack)

| 기술 | 용도 |
| --- | --- |
| **Python 3.x** | 메인 프로그래밍 언어 |
| **Tkinter** | 사용자 인터페이스(GUI) 및 오선지 캔버스 구현 |
| **NumPy** | 파형(Waveform) 데이터 생성 및 ADSR 연산 |
| **SciPy** | 고정밀 WAV 파일 바이너리 쓰기 |
| **Pygame** | 오디오 장치 제어 및 실시간 믹싱 재생 |

## 🎼 사용 가이드

1. **음표 입력**: 화면 상단의 음계 버튼을 클릭하여 멜로디를 쌓습니다.
2. **악보 확인**: 중앙 Canvas 영역에 그려지는 음표의 위치를 확인하며 작곡합니다.
3. **옵션 설정**: 반복 횟수와 파일명, 음 길이를 선택합니다.
4. **빌드 및 재생**:
* `🎶 생성`: 설정된 값으로 WAV 파일을 물리적으로 생성합니다.
* `▶️ 재생`: 생성된 최신 파일을 즉시 들어봅니다.


5. **데이터 보관**: `💾 저장` 버튼으로 작업 내역을 JSON으로 남겨 나중에 다시 불러올 수 있습니다.
