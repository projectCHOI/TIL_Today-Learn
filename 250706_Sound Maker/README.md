# Sound Maker 
- Mouse Click 8-bit Composer

**마우스 클릭 기반 8비트 작곡기 (Python / Tkinter / NumPy / Pygame)**

이 프로젝트는 **마우스로 음계를 선택하여 8비트 스타일의 음악을 작곡하고, WAV 파일로 생성·재생·저장**할 수 있는 간단한 작곡 도구입니다.
게임 개발 중 **BGM, 엔딩 음악, 효과음 제작**을 목적으로 설계되었습니다.

## 📌 주요 특징

* 🎹 **마우스 클릭으로 작곡**

  * 도~시 음계 + 옥타브(− / +) 지원
  * 쉼표(무음) 삽입 가능
* 🖼️ **오선지 시각화**

  * 선택한 음이 실시간으로 오선지(Canvas)에 표시
* 🎮 **8비트 사운드**

  * 정사각파(square wave) 기반
  * ADSR Envelope 적용
* 🎧 **WAV 파일 생성 & 재생**

  * 생성 즉시 게임에서 사용 가능
* 💾 **프로젝트 저장 / 불러오기**

  * JSON 기반 작곡 데이터 관리
* ⚙️ **BPM / 음 길이 / 반복 횟수 설정**

## 🎼 사용 방법

1. **음 선택**

   * 낮은 음 / 일반 음 / 높은 음 버튼 클릭
   * `쉼표` 버튼으로 무음 추가

2. **작곡**

   * 클릭한 순서대로 음이 저장됨
   * 오선지에 실시간 표시

3. **설정**

   * BPM (코드 내부 기본값: 120)
   * 음 길이 선택: `2분 / 4분 / 8분`
   * 반복 횟수 입력
   * 파일명 지정

4. **생성**

   * `🎶 생성` 버튼 → WAV 파일 생성

5. **재생**

   * `▶️ 재생` 버튼으로 즉시 확인

6. **저장 / 불러오기**

   * `💾 저장` → project.json 생성
   * `📂 불러오기` → 이전 작업 복원

## 🎵 종료 음악 예시 (우울한 분위기)

아래와 같은 음계 조합을 사용하면 어두운 엔딩 음악을 만들 수 있습니다:

```
도- 레- 미- 파- 쉼표
미- 레- 도- 쉼표
도- 쉼표
```

**권장 설정**

* BPM: 70~90
* 음 길이: 2분
* 반복: 1회
