 **사용자가 직접 입력한 음표 조합**으로 **8비트 음악을 생성**

---
## 1. 개요

* **목적:** 마우스 클릭으로 한국어 계이름(도\~시, 옥타브 ±)과 쉼표를 선택해 멜로디를 구성하고, 정사각파 기반 8비트 사운드를 **.wav**로 생성/재생/저장/불러오기 하는 데스크톱 GUI 도구.

* **핵심 기능:**

  * 음 선택(도/레/미/파/솔/라/시 + 저/고 옥타브) 및 쉼표 추가
  * 오선지 스타일 캔버스에 음표 위치 시각화(점·사각형)
  * BPM 기반 음 길이(2분/4분/8분) 적용, 반복 재생 시퀀스 생성
  * 정사각파 + ADSR(Attack/Decay/Sustain/Release) 엔벌로프로 합성
  * .wav 파일 생성/재생, 프로젝트 JSON 저장/불러오기

## 3. 오디오 합성 설계

### 3.1 기본 파라미터

* `sample_rate = 44100`
* `note_duration = 0.3` (기본 톤 생성 시 사용)
* `pause_duration = 0.05` (노트 간 휴지)
* `volume = 0.5`
* `BPM = 120` → `beat_per_sec = 2.0` → **4분음표 길이** `quarter_sec = 0.5s`

### 3.2 계이름-주파수 매핑 (C4 기준)

* `도 261.63`, `레 293.66`, `미 329.63`, `파 349.23`, `솔 392.00`, `라 440.00`, `시 493.88`
* 옥타브 처리: `note+` → ×2, `note-` → ÷2
* 쉼표: 주파수 0 처리

### 3.3 파형 및 엔벌로프

* **정사각파**: `sign(sin(2πft))` 기반 (진폭 스케일 0.5)
* **ADSR** (초 단위): `A=0.005, D=0.03, S=0.8, R=0.02`
* **클릭 노이즈 저감**: 2ms 페이드 인/아웃 적용

### 3.4 음 길이

* UI 선택값 → 실제 길이 변환:

  * `2분` = `quarter_sec * 2.0`
  * `4분` = `quarter_sec`
  * `8분` = `quarter_sec * 0.5`

## 5. 주요 함수 설명

* `adsr_envelope(total_samples, sr, A, D, S, R)`: ADSR 곡선 생성
* `get_note_seconds(label)`: UI 음 길이를 초로 변환
* `square_wave(freq, duration, volume)`: 정사각파 생성 + ADSR + 페이드
* `get_note_freq(note)`: 계이름을 Hz로 변환 (+/− 옥타브, 쉼표 처리 포함)
* `preview_tone(freq, dur, vol)`: 짧은 미리듣기 (현재 UI에서 직접 연결되지 않음)
* `update_staff()`: 오선지 캔버스 갱신(음표/쉼표/라벨)
* `add_note(note)`: 선택한 음 리스트에 추가 후 갱신
* `reset_notes()`: 초기화(리스트/반복/파일명)
* `delete_last_note()`: 마지막 음 삭제 후 갱신
* `generate_music()`: 시퀀스(반복 적용) → 파형 생성 → WAV 저장
* `play_music()`: 지정 파일 로드 및 재생(pygame)
* `save_project()`: 프로젝트 상태를 JSON으로 저장
* `load_project()`: JSON 로드 후 상태 복원(BPM 재계산 포함)

## 6. 데이터 포맷 (project.json)

예시 스키마:

```json
{
  "notes": ["도", "레", "미", "쉼표", "솔+"],
  "bpm": 120,
  "note_length": "4분",
  "repeat": "2",
  "filename": "click_composed.wav",
  "pause_duration": 0.05,
  "volume": 0.5
}
```

* **주의:** 현재 `load_project()`에서는 `pause_duration`, `volume` 복원 코드가 주석 처리되어 있어 실제 반영되지 않음.

## 7. 동작 흐름 요약

1. 사용자가 음 버튼 클릭 → `add_note()` → `selected_notes` 업데이트 → `update_staff()`로 시각화
2. 반복/음 길이/파일명 입력
3. `🎶 생성` 클릭 → 시퀀스(반복 적용) 합성 → WAV 저장
4. `▶️ 재생` 클릭 → 저장된 WAV 재생
5. `💾 저장`/`📂 불러오기`로 프로젝트 상태 관리
