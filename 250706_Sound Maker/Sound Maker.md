 **사용자가 직접 입력한 음표 조합**으로 **8비트 음악을 생성**

---
## 1. 개요

* **목적:** 마우스 클릭으로 한국어 계이름(도\~시, 옥타브 ±)과 쉼표를 선택해 멜로디를 구성하고, 정사각파 기반 8비트 사운드를 **.wav**로 생성/재생/저장/불러오기 하는 데스크톱 GUI 도구.

* **핵심 기능:**

  * 음 선택(도/레/미/파/솔/라/시 + 저/고 옥타브) 및 쉼표 추가
  * 오선지 스타일 캔버스에 음표 위치 시각화(점·사각형)
  * BPM 기반 음 길이(2분/4분/8분) 적용, 반복 재생 시퀀스 생성
  * 정사각파 + ADSR(Attack/Decay/Sustain/Release) 엔벌로프로 합성
  * .wav 파일 생성/재생, 프로젝트 JSON 저장/불러오기

## 3. 오디오 합성 설계

### 3.1 기본 파라미터

* `sample_rate = 44100`
* `note_duration = 0.3` (기본 톤 생성 시 사용)
* `pause_duration = 0.05` (노트 간 휴지)
* `volume = 0.5`
* `BPM = 120` → `beat_per_sec = 2.0` → **4분음표 길이** `quarter_sec = 0.5s`

### 3.2 계이름-주파수 매핑 (C4 기준)

* `도 261.63`, `레 293.66`, `미 329.63`, `파 349.23`, `솔 392.00`, `라 440.00`, `시 493.88`
* 옥타브 처리: `note+` → ×2, `note-` → ÷2
* 쉼표: 주파수 0 처리

### 3.3 파형 및 엔벌로프

* **정사각파**: `sign(sin(2πft))` 기반 (진폭 스케일 0.5)
* **ADSR** (초 단위): `A=0.005, D=0.03, S=0.8, R=0.02`
* **클릭 노이즈 저감**: 2ms 페이드 인/아웃 적용

### 3.4 음 길이

* UI 선택값 → 실제 길이 변환:

  * `2분` = `quarter_sec * 2.0`
  * `4분` = `quarter_sec`
  * `8분` = `quarter_sec * 0.5`
