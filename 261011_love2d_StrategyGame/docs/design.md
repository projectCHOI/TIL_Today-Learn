# impossibility Guild — 기획 기록

## 확정 규칙
- Lua + LÖVE2D 기반 턴제 전략 RPG.
- 육각 타일: 아군 지역 10~50, 적 지역 10~50, 총 20~100칸. 지역 경계 침범 가능.
- 카메라만 전장 중심을 기준으로 -45 / 0 / +45도 전환. 행동력 비용 없음.
- 지형: 평지 기준 위/아래 지역. 자연물: 나무·바위·풀.
- 건물 본체는 파괴 불가, 벽과 문은 파괴 가능. 문은 개폐 가능.
- 외부에서 내부 공격은 공격 경로 확보 시 허용. 내부에서 외부 공격은 불가.
- 내부끼리 전투 가능. 적 AI는 공격을 위해 나오거나 위험할 때 내부로 피신 가능.

## 구현 범위
맵·높낮이·자연물·건물·문 개폐·벽/문 테스트 파괴와 세 시점만 구현.

## 후속 구현
유닛·이동·턴·적 AI·시야와 공격 경로. 지형 및 자연물의 데미지/명중 보정은 나중에 추가.
지형 높이, 벽/문 HP는 현재 프로토타입의 임시 값.
